# AI-Driven-Market-Digital-Twins
**TrustWealth** 是一个旨在解决 AI 金融“黑盒信任危机”的综合决策系统。不同于传统的“只给结论”的预测模型，我们通过**验证优先 (Verification-First)** 的架构，确保从原始财报摄取到最终资产配置建议的每一步都具备逻辑一致性和审计透明度。

---

## 🌟 项目核心价值 (Core Value)

在金融领域，一个“看起来正确”的答案如果缺乏验证过程，就是一种风险。TrustWealth 的迭代核心在于：

* **从“结果驱动”转向“逻辑驱动”**：AI 不再只是“猜”一个数字，而是必须展示其推导逻辑（如计算过程、证据链接）。
* **从“盲目优化”转向“用户对齐”**：确保 AI 的盈利冲动永远不会触碰用户设定的硬性约束底线（如：绝对不碰烟草行业）。

---

## 🏗️ 系统架构与数据流 (System Architecture)

项目采用四层解耦架构，实现了从非结构化数据到可信决策的闭环。
